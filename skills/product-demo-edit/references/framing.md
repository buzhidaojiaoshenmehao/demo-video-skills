# 录屏构图与按时间点修订

## 目标边界先于缩放倍数

从源视频取出目标帧，标记必须展示的矩形，包含按钮、标签和关联状态。先扣除已有裁剪，再将源坐标映射到展示框；不要把原始桌面坐标直接当成最终画布坐标。

设裁剪后素材为 `W × H`，展示框为 `B_w × B_h`，contain 基础缩放为 `s=min(B_w/W,B_h/H)`，居中偏移为 `o=((B_w-sW)/2,(B_h-sH)/2)`。源目标矩形为 `[x,y,w,h]`，映射为 `[o_x+sx,o_y+sy,sw,sh]`。如果还发生二次裁剪或父级 transform，继续应用对应变换。

选择围绕目标中心的缩放 `z` 时，至少满足 `z·sw <= 可用宽度`、`z·sh <= 可用高度`，另留文字和指针的边距。平移须限制在不露空白且不裁掉必需内容的范围。数学约束只是候选值，最终检查渲染图。

## Remotion 工程中的实施

- 延续现有工程。只有需要具体 API 时才查当前安装版本对应的官方文档或可用 Remotion skill。
- 使用帧号驱动、可复现的插值；不要依赖浏览器运行时间或 CSS 自主播放动画。
- 把开始、到达、保持、恢复四个时间点显式写入镜头数据；转场重叠和 Sequence 的局部帧/全局帧要分别换算。
- 基础 contain 与高亮缩放分开控制。`scale=1` 只恢复基础版式，不保证整个应用都可见：检查 object-fit、裁剪与父级 overflow。
- 锚点必须来自所述按钮/状态。不要为了画面动感持续推近，也不要在长流程中追逐每次鼠标移动。

## 采样与验收

每个修订至少覆盖：区间前一帧、区间开始、中段、点击前后、结果出现、区间最后一帧、区间后一帧。脚本的区间采样能给出边界和中点，点击及异步结果出现时刻需要另外加到 `--times`。

记录每张图对应的「时间、必须可见内容、是否完整、是否可读」。缩略联系表用于查漏；小字和按钮必须看原尺寸帧。长区间在没有其他操作信息时增加采样，不用一个中点代表整段。
